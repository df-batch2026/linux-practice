Yamato IT Asset Management System

Developed a web-based IT Asset Management System during my internship at Yamato Logistics India Pvt. Ltd. to centralize and streamline the management of organizational IT assets that were previously maintained through Excel files.

The system provides a centralized dashboard for asset registration, inventory management, employee assignment, asset returns, searching/filtering, employee management, data uploads, reporting, and asset tracking.

Key Features
📊 Interactive dashboard with asset analytics
💻 IT asset registration and inventory management
👨‍💼 Employee management and asset assignment
🔄 Asset issue/return tracking
🔍 Asset search and filtering
📁 Excel/CSV data import using Pandas
🗄️ Dynamic database and table creation using MySQL & SQLAlchemy
🔐 Password-protected asset deletion
📈 Asset depreciation, inventory value, and status reports
📝 Dynamic fields based on uploaded/user-provided data
💾 Automatic storage of uploaded data in the database
My Contribution

I was involved in the end-to-end development of the system, including designing and implementing the frontend/UI, developing the file-upload and data-processing functionality, integrating the database, and connecting the different components of the application.
